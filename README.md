
# Zapix
## Features

* Developed a **Zapier-inspired workflow automation platform** that enables users to create and execute multi-step automation workflows across different applications.
* Implemented a **Kafka-based publisher–consumer architecture** with the **Transactional Outbox Pattern** to ensure reliable event delivery and maintain data consistency across distributed services.
* Built a **scalable backend** using **Node.js, Express.js, PostgreSQL, and Prisma ORM** for workflow orchestration, persistence, and REST API management.
* Developed a **responsive Next.js frontend** with an intuitive interface for creating, managing, and monitoring automation workflows.
